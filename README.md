# 新闻选题调研助手 (AI News Research Assistant)

一个新闻选题调研助手Agent，为媒体从业者提供智能化的行业研究工具。

## 核心功能

### 🎯 行业新闻助手
- 针对不同行业提供专属的新闻调研能力
- 支持行业：智慧交通、金融、医疗健康、能源等
- 一键切换，快速进入专业领域研究

### 📊 深度调研
- 多 Agent 协作研究系统
- 支持流式输出，实时展示研究进度
- 自动生成行业分析报告

### 📰 资讯聚合
- 多来源新闻自动采集（国家发改委、国务院、交通运输部等）
- 政策、研报、新闻分类整理
- 支持收藏和管理感兴趣的内容

### 💬 智能问答
- 基于本地知识库的 RAG 问答
- 支持文档上传和切片管理
- 会话管理与上下文记忆

### 📈 数据可视化
- 自动生成行业分析图表
- 支持多种图表类型（折线图、柱状图、饼图等）
